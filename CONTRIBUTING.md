# Contributing to GlassRank

Thanks for your interest! Proposals that change rating behavior should include
simulation results from `@glassrank/sim` showing their effect.

## Developer Certificate of Origin

All commits must be signed off, certifying the [Developer Certificate of
Origin](https://developercertificate.org/):

```sh
git commit -s -m "Your message"
```
